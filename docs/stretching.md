# 拉伸分頁規格（拉伸對話維護）

更新：2026-11-14　狀態：第一版定案並實作於 `app/js/stretch.js`、`app/css/stretch.css`

## 使用者定案
- 依建議的預設規格開始做。
- 左右邊順序：**可以在設定切換**（先左／先右，預設先左）。
- 示意圖：第一版**純文字**，資料保留之後加圖的空間。
- 語音：**第一版就做**，唸出動作名稱與換邊提示（沒有預錄檔的字用手機語音）。

## 部位分組
肩頸、背部、胸、手臂、髖臀、腿部（動作庫用這些分類篩選）。

## 內建套組
| 套組 | 用途 | 停留 |
|---|---|---|
| 肩頸舒緩 | 看螢幕、低頭太久 | 30 秒 |
| 久坐舒緩 | 坐一整天：髖、下背、腿 | 30–40 秒 |
| 運動後收操 | 跑步／重訓後全身 | 30–40 秒 |
| 早晨喚醒 | 輕鬆、短停留 | 20 秒 |
| 睡前放鬆 | 溫和、停留較久 | 45–60 秒 |

## 動作資料
每個動作：名稱、部位、是否分左右、預設秒數、步驟說明、注意事項（`img` 欄位預留給之後的示意圖）。
第一版內建約 20 個動作。

## 時間規則
- 停留秒數可改，5–300 秒，以 5 秒為單位。
- 每個動作開始前有 **5 秒準備**（畫面預告動作、語音唸名稱）。
- 分左右的動作：左（或右）→ **3 秒換邊**（音效＋語音「換右邊」＋背景顏色加深一階）→ 另一邊。
- 總時長＝各動作停留（左右算兩次）＋換邊＋準備時間。

## 自訂流程
- 從動作庫加入動作、改秒數、上下移、刪除，取名後儲存（最多 20 個流程、每個最多 30 個動作）。
- 內建套組可「複製並編輯」，原套組不變。
- 儲存在手機本機（`st.custom`），包含在匯出／匯入備份內。

## 進行中畫面（柔和放鬆、薄荷綠）
- 淺色：淡薄荷背景；深色：森林深綠背景。
- 顯示：進度（3/8・流程名稱）、動作名稱、左邊／右邊、倒數數字與進度環、步驟說明與注意事項、下一個動作預告。
- 準備時間：進度環變淡，顯示「準備・下一個」。
- 按鈕：上一個、+10 秒（停留中才能按）、跳過；共用的暫停／繼續、結束（暫停後出現）。
- 上一個：在目前動作已做超過 3 秒時回到這個動作開頭，否則回到前一個動作。
- 螢幕保持常亮（共用 `P.wake`）。
- 完成後用共用完成畫面（時長、動作數、心情），紀錄類型 `st`。

## 儲存 key
- `st.custom`：自訂流程 `[{id,name,items:[[動作id,秒],...]}]`
- `st.first`：先做哪一邊 `'L'|'R'`
- `st.last`：上次練習的流程 id（快速開始）

## 預錄語音（已完成 2026-11-16）
- `app/audio/st/{f,m}/`：21 個動作名稱 `mv_<動作id>`，加上 `w_left` 左邊、`w_right` 右邊、`w_swl` 換左邊、`w_swr` 換右邊、`w_first` 先做、`w_next` 下一個。
- 聲音沿用呼吸／運動：女聲 HsiaoChen（pitch -10Hz、rate -20%）、男聲 YunJhe（atempo 0.85），去頭尾靜音。YunJhe 常拒絕較長的詞，改成分段產生再接起來。
- 播報：準備時「（下一個，）動作名稱（，先做左邊）」，換邊時「換右邊」；片段依序接起來播。缺任何片段就整句改用手機語音。「開始」「結束」用核心的預錄。暫停或結束時立即停止語音。
- 新增內建動作時，要補產生這個動作的兩個聲音檔。
