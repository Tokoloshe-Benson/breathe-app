# 習慣分頁

由習慣對話維護。程式在 `app/js/habit.js`、`app/css/habit.css`。

> 第一版（2026-11-16）是照討論時提出的「第一版範圍（建議）」直接做的；使用者還沒逐項確認，以下都可以再調整。

## 定位
- 自動記錄呼吸、運動、拉伸的完成，也可以自己新增習慣，例如喝水、早睡。
- 原本規劃的「我的」分頁已經併入這裡：紀錄、月曆、連續天數都在習慣分頁；設定從右上角 ⚙️ 進入。

## 練習習慣（搭配呼吸、運動、拉伸分頁，2026-11-16 加入）
依其他分頁的功能，先做出適合的習慣功能。這些也是先照建議做的，可以再調整。
- **指定項目**：新增習慣時選「練習」，可以綁定某一個呼吸法、運動菜單或拉伸套組，例如「睡前 4-7-8」只在做 4-7-8 呼吸時打勾；也可以選「任何呼吸都算」。名稱沒填的話，自動用項目名稱。
- **每天目標**：做一次就打勾、幾分鐘（同一天的練習時間會加總），或幾次。內建的呼吸、運動、拉伸也可以改目標，例如「呼吸每天 10 分鐘」。
- **今天清單顯示進度**，例如「今天 7/10 分鐘」。
- **去練習**：還沒完成的練習習慣有「去練習」按鈕，會切到該分頁；如果有指定呼吸法或拉伸套組，會順便把它設成那個分頁的「上次使用」，在快速開始就能直接點到。運動菜單目前只切換分頁。
- **補卡頁**下方會列出那天做過的練習（名稱、時間、時長、心情）。
- 刪除練習習慣只會刪掉打勾紀錄，練習紀錄本身不受影響。

## 畫面
1. **上方統計**：連續天數（呼吸、運動、拉伸任一種有做就算一天，補卡也算）、今日完成（已完成數／顯示中的習慣數）、練習次數（練習紀錄總筆數）。
2. **今天清單**：每個習慣一列。
   - 呼吸、運動、拉伸：今天有練習紀錄就自動打勾；沒有紀錄也可以手動打勾。
   - 有做／沒做：點圓圈打勾或取消。
   - 計次：按 − ＋ 調整，達到目標（例如喝水 8/8）才算完成。
   - 完成時有短音效和震動（依設定開關）。
   - 副標題：每日習慣顯示「連續 N 天」，每週習慣顯示「本週 x/y 天・連續 N 週」。
3. **月曆**：可以切換到前幾個月，不能看未來。三色點代表呼吸（靛紫）、運動（珊瑚橘）、拉伸（薄荷綠）；灰點代表那天有完成自訂習慣。點過去的日期可以**補卡**，也就是補打勾那天的習慣。
4. **練習紀錄**入口：開啟共用的練習紀錄頁（`openLog(rHb)`），可以補選心情和補寫備註。
5. **管理習慣**：新增、編輯、隱藏、刪除。
   - 呼吸、運動、拉伸：不能刪除、不能改名，只能改頻率或隱藏。
   - 自訂習慣：可以設名稱、方式（有做／沒做、計次）、每天目標次數、頻率（每天、每週幾天）、顏色（灰、藍、粉、琥珀、棕、深灰，避開三個分頁的主色）。
   - 刪除前會確認，該習慣的打勾紀錄也會一起刪除。

## 規則
- **每日習慣**：連續天數算到今天；今天還沒做的話，從昨天往回算，不會因為今天還沒做就歸零。
- **每週習慣**（例如運動每週 3 天）：週一到週日算一週，達到天數就算達標。連續數算的是「連續達標週數」；本週還沒達標的話，從上週往回算。
- **補卡**：任何過去的日期都能補，沒有次數限制。

## 資料（localStorage，key 前綴 `hb.`）
- `hb.habits`：`[{id, name, kind:'auto'|'check'|'count', src?, ref?, goal?:'once'|'min'|'times', target?, freq:'daily'|'weekly', per?, color?, hidden?}]`
  - `ref` 對應練習紀錄的欄位：呼吸 `breathId`、運動 `routine`、拉伸 `routineId`。
  - 第一次打開時會自動建立呼吸、運動、拉伸三個 `auto` 習慣，`id` 分別是 `breath`、`ex`、`st`。
- `hb.marks`：`{ 'Y-M-D': { 習慣id: 次數 } }`，存手動打勾、計次和補卡。
- 練習完成讀取共用的 `LOG()`（type 為 breath、ex、st），習慣分頁不會改動練習紀錄。
